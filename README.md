# SoftUni Programming Fundamentals with Java

Solutions for the SoftUni Programming Fundamentals with Java course: basic syntax, data types, arrays, methods, lists,
objects and classes, associative arrays, text processing and regular expressions. One class per problem.

## Run

Needs JDK 25. Every lecture is its own Gradle project with a wrapper and JUnit tests.

```bash
cd 006-Exercise-Arrays
./gradlew build      # compiles and runs the tests
```

Or open the lecture folder in IntelliJ IDEA and run a class's `main`.
